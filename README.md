# Java: estudos e projetos

Material didático, anotações e projetos desenvolvidos durante o estudo de Java, dos fundamentos da linguagem à programação orientada a objetos. São mais de 30 programas, entre aplicações de console e aplicações gráficas em Swing e JavaFX. Cada programa é um projeto independente, com o código comentado em português.

## Cursos

O conteúdo da pasta [Material didático](https://github.com/marcospontoexe/Java/tree/main/Material%20did%C3%A1tico) foi desenvolvido durante dois cursos do Curso em Vídeo:

1. [Curso de Java para Iniciantes](https://www.youtube.com/watch?v=sTX0UEplF54&list=PLHz_AreHm4dkI2ZdjTwZA4mPMxWTfNSpR)
2. [Curso de POO Java (Programação Orientada a Objetos)](https://www.youtube.com/watch?v=KlIL63MeyMY&list=PLHz_AreHm4dkqe2aR0tQK74m8SFe-aGsY)

## Tecnologias

- **Java**: os projetos são compilados para o Java 18 (o de JavaFX, para o Java 8).
- **Swing** e **JavaFX** (com FXML) nas interfaces gráficas.
- **NetBeans**, com projetos Ant.

## Como executar

Cada pasta é um projeto NetBeans independente, com o código em `src/`. É preciso ter o Java 18 ou mais recente instalado.

- **Aplicações gráficas:** baixe o `.jar` e execute com `java -jar Triangulos.jar` (ou com um duplo clique). O `Genio.jar` precisa da pasta `lib/` que fica ao lado dele em `dist/`.
- **Aplicação JavaFX:** o JavaFX não vem mais com o Java desde a versão 11, então o `OlaMundo.jar` precisa do JavaFX SDK, disponível em [openjfx.io](https://openjfx.io/). Baixe o SDK da mesma versão do seu Java, descompacte e execute o comando abaixo, trocando o caminho pelo da pasta `lib` do SDK. Os avisos de "restricted method" que o Java mostra no terminal não impedem a execução.

  ```powershell
  java --module-path "C:\javafx-sdk-25.0.4\lib" --add-modules javafx.controls,javafx.fxml -jar OlaMundo.jar
  ```
- **No NetBeans:** abra a pasta do projeto em *File > Open Project* e execute com F6.
- **Pelo terminal:** compile e execute a classe principal, indicada em `main.class` no arquivo `nbproject/project.properties`:

  ```bash
  cd "Material didático/Curso em vídeo/05-operadores/01-BibMath"
  javac -encoding UTF-8 -d out src/bibmath/BibMath.java
  java -cp out bibmath.BibMath
  ```
